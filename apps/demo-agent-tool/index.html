Architecture

Parent agent · GoogleGenAIAdapter (Gemini)

Child agent · BuiltInAIAdapter (on-device, via Chrome Prompt API)

The parent has one tool, rewrite_text, wired up with createAgentTool. When the parent calls it, the child agent runs locally and its thinking / text_delta events stream into the onToolEvent handler — you'll see them appear inline below the tool call.
