Architecture

Parent agent: an orchestrator that picks tools. It runs through its own AgentRunner + GoogleGenAIAdapter.

Child agent: a specialised rewriter. It runs through a separate AgentRunner + GoogleGenAIAdapter with its own AgentConfig.

createAgentTool wires the child as the parent's only tool, rewrite_text. The child's text_delta events stream into the parent's onToolEvent handler — you'll see them appear inline below the tool call.
