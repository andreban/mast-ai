What this shows

GoogleGenAIAdapter accepts an optional nativeTools array that is forwarded directly to Gemini alongside any function declarations from the ToolRegistry. This demo passes [{ googleSearch: {} }] so the model can ground answers in live web results.

Native tools cover Gemini's built-in tools — googleSearch, codeExecution, urlContext — without needing adapter subclasses for each.
